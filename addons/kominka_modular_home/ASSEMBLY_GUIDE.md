# 組み立て・使用例 / Assembly guide

このキットは古民家を題材とするゲーム用のオリジナル意匠です。特定地域・年代の建物の実測復元や建築施工図ではありません。

## まず使用例を開く

1. ZIPを展開し、商品フォルダ内の `addons/` を自分のGodotプロジェクト直下へコピー。
2. インポート完了後、`addons/kominka_modular_home/demo/Exterior.tscn` を開き、F6で実行。
3. Tabで `DemoRoom`（室内断面）、`Exterior`（外観）、`Showcase`（全種類）を切り替える。
4. マウス左ドラッグで回転、ホイールで拡大縮小、Rで初期視点、Hで屋根と天井の表示切替。
5. 個別配置は `scenes/*.tscn` をドラッグ＆ドロップ。GLBだけを配置するとコリジョンは付きません。

両版とも同じ `res://addons/kominka_modular_home/` を使います。ひとつのプロジェクトには一方を導入し、版を切り替えるときはフォルダ単位で入れ替えてください。plugin.cfgやプラグイン有効化は不要です。project.godotは配布物に含まれません。

## 基本の組み方

寸法はm、GodotのYが上です。Xが間口、Zが奥行き。壁と建具の正面は+Z。原点は設置面の中心です。スナップ0.9mを基本に、建具や厚みの調整には0.01mを使います。

| 部材 | 配置・寸法 |
|---|---|
| foundation | 1.8 × 1.8m、地面Y=0、上端Y=0.45 |
| floor_wood | 1.8 × 1.8m、Y=0.45で床上端Y=0.57 |
| tatami | X=0.9 / Z=1.8m、Y=0.57、畳上端約0.631m（縁を含む） |
| post / wall | Y=0.57、高さ2.4m。柱芯1.8m間隔 |
| doorway | 幅1.8mの開口フレーム。中央は通過可能。柱・上枠・敷居を個別衝突形状化 |
| shoji / fusuma / door_wood | 幅0.9m、高さ2.05m。独立パネル。手動でスライド配置できる静的モデル |
| engawa | 1.8 × 0.9m、高さ0.49m、Y=0。床より一段低い縁側 |
| beam | X方向1.8m。Z方向に使うときY回転90度 |
| roof_slope | 幅1.8m、水平奥行3.1m、立上り1.35m。+Z側が軒、-Z側が棟 |
| roof_ridge | X方向1.8m。棟に連続配置 |
| gable | 幅5.4mの妻面用三角壁。屋根の幅が変わる場合は原本を編集 |
| sill / ceiling | 土台や天井の補完。用途に合わせて反復配置 |

### 7.2 × 5.4mの家を作る

- 基礎と床：X=-2.7,-0.9,0.9,2.7、Z=-1.8,0,1.8の12点に反復配置。
- 柱：前後Z=±2.7、X=-3.6,-1.8,0,1.8,3.6。左右はX=±3.6、Z=±0.9に追加。
- 壁：前後の中心X=-2.7,-0.9,0.9,2.7。左右の中心Z=-1.8,0,1.8はY回転90度。
- 出入口：壁をdoorwayへ差し替え、必要なら独立した建具を追加。扉を開けるにはパネルのX位置を移動。
- 屋根：各X列にroof_slopeをY=2.97、Z=1.55で配置。反対面はZ=-1.55、Y回転180度。
- 棟：各X列にroof_ridgeをY=4.32、Z=0で配置。
- 妻面：gableをX=±3.6、Y=3.145、Z=0、Y回転90度で配置。
- 縁側：各X列のZ=3.15、Y=0。入口前にstepとstone_pathを追加。

`demo/*_layout.json` に全配置座標とアセットIDを記録しています。デモのArchitecture / Furnishings / Garden / Roofから必要な配置を複製できます。Showcaseは一覧用の拡縮表示です。実寸配置には個別シーンまたは室内・外観デモを使ってください。

## 制限

- 切妻の瓦屋根が基本。茅葺き・入母屋・曲がり屋・複数階・屋根の谷や隅棟は未収録。
- 開閉アニメーション、プレイヤー、建築エディタ、自動組立ツールは含みません。Godot上で部材を配置するキットです。
- 部材は静的コリジョン。装飾の衝突は近似形状です。屋根は斜面に沿う12分割ボックス。見た目の非表示は衝突の無効化ではありません。
- 木材・瓦等の接合に意図的な重なりがあります。単一の3Dプリント用水密メッシュではありません。
- ノーマルはプロシージャルな表面微細形状。高ポリゴン原型からのベイクではありません。ORMのR=AOは白の未ベイク値、G=Roughness、B=Metallic。
- 写真用の地面・ライト・カメラ・UI以外、デモの家はすべて収録シーンから構成しています。
